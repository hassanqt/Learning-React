# 🧠 learning-react

> My public journey learning React — from day one, one commit at a time.

This repo is where I'm learning **React** out loud. No polished portfolio pieces (yet), no copy-pasted tutorials pretending to be my work — just raw progress, messy commits, and notes to future-me.

## 🔥 Why this repo exists

I started learning web development about **2 months ago** from absolute zero:

- ✅ HTML & CSS fundamentals
- ✅ Vanilla JavaScript
- ✅ Tailwind CSS
- ✅ Component libraries (DaisyUI)
- 🚧 **React** ← I'm are here

React felt like the natural next step. I wanted to stop *copying* UIs and start *thinking* in components. So here we are — day one.

## 📅 The plan

**Consistency over intensity.** I'd rather code 20 minutes a day than binge 8 hours once a month.

- Follow a structured path (numbered folders = lessons)
- Rebuild each exercise from memory after finishing it
- Ship small things, often
- Write down what confused me — that's where the real learning lives
